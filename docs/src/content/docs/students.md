## Open

Install [`uv`](https://docs.astral.sh/uv/getting-started/installation/), then run this in the assignment folder:

```bash
uvx marimo edit --sandbox hw.py
```

The first start takes a while.

## Work

Fill in the `...`.
Keep each function self-contained: use its arguments, the imports at the top, and other functions.
Don't rename functions or edit the test cells.

The check cell under each question runs its public tests as you edit.
Gradescope runs hidden tests on top of these.

## Submit

1. Save the notebook.
2. Click **Export submission** at the bottom.
3. Download the zip and upload it to Gradescope.

The export runs the public tests on the saved file and lists anything wrong.
Written answers go into a PDF in the zip.
